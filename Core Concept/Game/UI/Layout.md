# UI Layout

> The production plan calls UI "the moat" and gates Patreon funding on the shell. This file was empty; this skeleton gives the design a spine. Fill per-screen.

## Design pillars (proposal)
1. Diegetic first: UI reads as part of the world (Rei-vision, not menus)
2. One hand: every core action reachable one-handed (combat UX)
3. Info on demand: nothing permanent on screen except HP/Rei
