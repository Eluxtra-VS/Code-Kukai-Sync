# Core Concept

Index of the core creative content of Code: Kukai — everything shared between the story and game, plus game-specific and story-specific documents.

## Subfolders

- [[Shared]] — world-building elements used by both story and game: power system, locations, entities, miscellaneous mechanics.
- [[Story]] — narrative content: characters, lore, factions.
- [[Game]] — game design content: systems, UI.
