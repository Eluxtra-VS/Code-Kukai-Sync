# Entities

Index of all entity types in Code: Kukai — beings that exist outside normal human categories.

## Files

- [[Reiva]] — sentient spirit companions born from the Luz Tree in the Oscuro; the source of all awakened power; bond with a human host to survive.
- [[Kukai]] — failed human-Reiva bonds; fully conscious, corrupted, trapped; retain memory and identity; one white body part; shapeshift freely.
- [[Kukai Shades]] — corrupted proto-Reiva in the lower Oscuro; corrupt newly-born Reiva and prey on unawakened Kyumin.
