# Bond Stages

## Short Definition

**Bond Stages** describe how control and cooperation between a human host and their Reiva evolve. They are narrative and mechanical milestones that affect power quality, control balance, and risk.

---

## Stage Overview

| Stage | Host Control | Reiva Control | State |
|---|---|---|---|
| **Unstable** | Unshared — all-or-nothing | Unshared — all-or-nothing | Volatile, dangerous |
| **Zanshin** | ~75% | ~25% | Training arc, growing trust |
| **Union** | ~50% | ~50% | True partnership |

---

## Stage 1 — Unstable

> _"The default starting state. Nothing is shared — control is seized, not given."_

**Control:** All-or-nothing. At any given moment it is either 100% the host or 100% the Reiva — there is no middle ground, no partial sharing, no cooperation. The switch is abrupt and uncontrolled.

**Characteristics:**
- Abrupt switches between host and Reiva control with no warning.
- Berserk takeovers when the Reiva pushes back against the host's resistance.
- Memory gaps for the host after Reiva-controlled episodes — they wake up not knowing what happened.
- Uncontrollable surges of power followed by exhaustion and confusion.

**Risk:**
- Highest chance of irreversible bond damage.
- Repeated Reiva dominance episodes accelerate Kukai-adjacent behaviour.
- High Rei waste per action — the all-or-nothing split is maximally inefficient.

**Transition to Zanshin:** Repeated successful cooperative use in low-risk scenarios. Trust-building micro-beats. The host must choose to yield small things rather than fight for total control — the choice is what opens the next stage, not time.

---

## Stage 2 — Zanshin

> _"The host can now hear the Reiva. That is enough to begin."_

**Control:** ~75% Host / ~25% Reiva. The host remains dominant but the Reiva has consistent, genuine presence.

**Characteristics:**
- The host senses the Reiva as impressions, nudges, and half-formed instincts.
- Basic shared techniques become possible without full takeover.
- Spiritual perception opens — can sense other Reiva, detect Kukai traces.
- Basic Rei channeling with meaningfully greater efficiency than Unstable.

**Narrative use:** This is the training arc state. Where characters learn to rely on and trust each other. Where most of the story's development scenes live.

**Transition to Union:** A major trust event — one saves the other; mutual sacrifice; prolonged joint success; a psychological breakthrough where the host accepts the Reiva as an ally rather than a managed threat. The event must be genuine. A mechanical milestone without the emotional foundation does not produce the transition.

---

## Stage 3 — Union

> _"They no longer coordinate. They simply move."_

**Control:** ~50% Host / ~50% Reiva — true, voluntary partnership.

**Characteristics:**
- Seamless coordination in combat without conscious communication.
- Shared consciousness during high-intensity moments.
- Advanced hybrid techniques become reliable.
- Near-maximum Rei efficiency — the shared resource is used at its best.

**Drawbacks:**
- Union is powerful but demanding.
- Pushing beyond the bond's limits under extreme stress can snap it — the bond can break at Union the same as at any other stage, just from a different kind of pressure.

---

## Bond Strengthening

Progress triggers are narrative beats, not metrics:

| Transition | What Produces It |
|---|---|
| Unstable → Zanshin | 3+ successful low-stakes shared actions; the host chooses to yield rather than fight |
| Zanshin → Union | Major shared event where host and Reiva protect each other; genuine emotional acknowledgment of partnership |

**Methods that strengthen the bond at any stage:**
- Shared memory exchange — the host experiences a Reiva memory voluntarily.
- Trust trials — each deliberately yields control in low-stakes contexts.
- Naming — learning the Reiva's true name; unlocks concealed techniques.
- Mutual sacrifice — giving up something significant for the other.

---

## Consequences of Bond Damage

| Severity            | Effect                                                                                |
| ------------------- | ------------------------------------------------------------------------------------- |
| **Mild**            | Temporary loss of shared perception; reduced Rei efficiency; memory fuzziness         |
| **Severe**          | Reiva rejects host — partial takeover; high corruption risk                           |
| **Permanent break** | Reiva flees or dissipates; host loses Rei access; potential permanent physical damage |
|                     |                                                                                       |
