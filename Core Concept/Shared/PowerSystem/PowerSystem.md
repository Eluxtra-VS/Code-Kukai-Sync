# PowerSystem

Index of all power system documents. Read in this order for full comprehension: Rei → Luz → Kuro → Emotions → Pressure → Awakening → Bonding → Bond Stages → Progression → Classes → then individual class files.

## Core Energy Files

- [[Rei]] — the fundamental lifeforce; splits into Luz (positive) and Kuro (negative); two reserves: Core (sustains bond) and Reserve (expendable).
- [[Luz]] — positive Rei; long-game energy; saturation, disable, overflow; powered by Tranquility, Joy, Bravery.
- [[Kuro]] — negative Rei; short-game energy; immediate precision damage; powered by Rage, Sorrow, Fear. Hidden from main cast at story start.
- [[Emotions]] — six emotional states (3 Luz, 3 Kuro) that determine Rei expression; each ability pairs a Class with an Emotion.
- [[Pressure]] — accumulated unresolved emotion; the seed of Reiva activity; the true antagonist of the system.

## Progression & Bonding Files

- [[Awakening]] — the event where dormant Reiva activates; determines Type by first resolution; includes in-game Awakening mechanic.
- [[Bonding]] — the long-term trust-building process between host and Reiva.
- [[Bond Stages]] — *(now in Misc/)* Unstable → Zanshin → Union; control split evolves through narrative trust beats.
- [[Progression]] — all three path stages in detail: Akarui (Unstable/Zanshin/Union), Weaver (Loom/Seam/Unravel), Reiki (Connection/Hinan/Blame).
- [[Human Progression]] — non-awakened human path; Relics + Chip system; multiple Relics form a moveset.

## Class Files

- [[Classes]] — overview of all four Classes and how they differ across types.
- [[Vigor]] — desire to be enough; reverberation and amplification; passive whole-body for Weavers.
- [[Pulse]] — desire to reach; projectiles (Akarui), body emission (Weaver), Anchor network (Reiki).
- [[Forge]] — desire to build; independent constructs (Akarui), body transformation (Weaver), Anchor reshaping (Reiki).
- [[Veil]] — desire to control conditions; condition-gated abilities; unblockable when condition is met.

## Technique Files

- [[Signature Design]] — the Pressure→Ability framework for creating or revising signatures; class comes from desire, not function.
- [[Manifestation]] — named unique signature ability of all Akarui; evolves with the character.
- [[Buki]] — technique for channelling Luz into objects; pre-awakening path; considered low-status by awakened community.
- [[Summon]] — high-level technique; Reiva consciousness transferred into a Vessel to fight alongside host.
- [[Transference Technique]] — learned in the Oscuro; allows control of Reiva consciousness into objects; required for Summoning.

## Subfolders

- [[Signatures]] — all named signature abilities.
