# Types

Index of the three awakened Types and the pre-awakening state. Type is determined by the first resolution of Pressure at Awakening.

## Files

- [[Akarui]] — External path; Pressure resolved outward; produces a named Manifestation; stages: Unstable → Zanshin → Union.
- [[Weaver]] — Internal path; Pressure turned back on the self; channels Luz into a Thread (specific body part); stages: Loom → Seam → Unravel.
- [[Kyumin]] — pre-awakening state; dormant Reiva bond; heightened sensitivity; can use Buki; at risk of Kukai transformation if Pressure reaches critical without resolution.

## Subfolders

- `Sub-Paths/` — Reiki (advanced Buki Sub-Path with remote Anchor control).
