# Story

Index of all story content for Code: Kukai.

## Planning & Controls

The Planning folder contains all arc planning, tracking, and control documents:

- [[Character Pressure Matrix]] — every documented named character's Pressure, coping behavior, power mirror, arc movement, and scene-proof status.
- [[Story Architecture Control]] — arc structure and locked/working/open decisions.
- [[Story Roadmap Tracker]] — scene cards, arc status, character perfection checklist.
- [[Story Arcs]] — arc structure overview (1–4).
- [[Arc Treatment (In-Depth Draft)]] — expanded scene-level draft.
- [[Comic Manga Integration Plan]] — visual adaptation plan, page rules per character.
